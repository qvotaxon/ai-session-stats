# Instructions for AI agents

These instructions are for every AI agent that works in this repository: Claude Code (which loads this file through `CLAUDE.md`), and GitHub Copilot's cloud agent, CLI, code review and VS Code chat. Other Copilot IDE chats get the ADR rules from `.github/instructions/adr.instructions.md` directly. They need no plugin. Where a plugin skill says something different, this file and the files it names win. People are welcome to read them too.

## Architecture Decision Records

ADRs in `docs/adr/` use the Alexandrian template, always. Before you create, convert or edit any file in `docs/adr/`, read `.github/instructions/adr.instructions.md` (the rules, including how to pick the next number) and `docs/adr/template.md` (the template). Never rewrite an existing decision.
